# Игра «Крестики-нолики»

Консольная реализация игры «Крестики-нолики» на поле 3 × 3 с полной логикой игры, обработкой ошибок ввода и тестированием основной функциональности.

## Описание проекта

В игре участвуют два игрока:

- `X` — крестик
- `O` — нолик

Первым всегда ходит `X`. Игроки по очереди ставят свой символ в свободную клетку. Побеждает тот, кто первым соберёт линию из трёх символов по горизонтали, вертикали или диагонали. Если поле заполнено и победителя нет — объявляется ничья.

## Возможности

- инициализация игрового поля 3 × 3
- вывод поля в консоль
- обработка ходов пользователя
- проверка победы и ничьи
- обработка некорректного ввода через исключения
- unit-тесты логики игры
- плей-тесты

## Формат поля

```
   1 2 3
  ------
a| O _ _
b| _ X _
c| _ _ _
```

- `a, b, c` — строки
- `1, 2, 3` — столбцы
- `_` — пустая клетка

## Формат хода

Ход вводится в формате:

```
{letter}{digit}
```

Примеры:
- корректно: `a1`, `b2`, `c3`
- некорректно: `a4`, `d2`, `11`, `a 1`

При ошибке ввод повторяется.

## Архитектура

Основные методы:

- `initializeGame()` — создание поля
- `formatGame()` — форматирование поля
- `isMoveAvailable()` — есть ли свободные клетки
- `checkWin()` — проверка победителя
- `move()` — выполнение хода
- `runGame()` — основной цикл игры

## Логика работы

1. Создаётся поле
2. Выводится в консоль
3. Игрок вводит ход
4. Проверка хода
5. Обновление поля
6. Проверка победы или ничьи
7. Повтор до конца игры

## Обработка ошибок

Используются `IllegalArgumentException`:

- неверный формат
- выход за границы
- занятая клетка

## Тестирование

Покрываются:

- создание поля
- форматирование
- доступность ходов
- проверка победы
- выполнение хода
- игровые сценарии

## Запуск

```

```

