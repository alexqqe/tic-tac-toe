# Игра «крестики-нолики»

## Задача

Разработайте игру «крестики-нолики» на поле 3 × 3 и покройте весь функционал тестами.

### Правила игры

- Игра проходит на квадратном поле размером 3 × 3 клетки. 
- Участвуют два игрока, каждому назначается символ: «крестик» (X) или «нолик» (O). 
- Первым ходит игрок «крестик» (X). 
- Во время своего хода игрок может поставить назначенный ему символ на любую незанятую клетку. 
- Если один из игроков сделал ход и после этого все его символы заполнили всю строку, столбец или диагональ поля, то он признаётся победителем.
- Если на поле нет свободной клетки и из-за этого игрок не может сделать ход, то объявляется ничья.

## Требования к реализации

### Взаимодействие с пользователем

Когда игра начинается, в консоли отрисовывается поле игры. После этого игрок с символом X выбирает, на какую клетку он поставит «крестик». После его хода снова отрисовывается уже обновлённое поле игры, и ход переходит к «нолику». Когда игра заканчивается, отрисовывается финальное поле, и в консоль выводится информация о победителе или объявляется ничья.

### Отрисовка поля

Поле должно отрисовываться в следующем формате:

```
   1 2 3
  ------
a| O _ _ 
b| _ X _ 
c| _ _ _ 
```

- a, b, c — индексы строк;
- 1, 2, 3 — индексы столбцов;
- O — символ игрока «нолик»;
- X — символ игрока «крестик»;
- _ — символ пустой ячейки на поле.

### Формат хода пользователя

Когда игрок выбирает клетку, то вводит ход в следующем формате: `{letter}{digit}`, где буква — номер строки, а цифра — номер столбца.

Примеры валидных ходов: `a1`, `c3`, `b3`.

Примеры невалидных ходов: `a4`, `d2`, `11`, `1 1`, `a 1`.

Ход должен валидироваться. При ошибке валидации необходимо попросить игрока повторить ход.

### Пример игры в консоли

```
   1 2 3
  ------
a| _ _ _ 
b| _ _ _ 
c| _ _ _ 

(X): b2
   1 2 3
  ------
a| _ _ _ 
b| _ X _ 
c| _ _ _ 

(O): a1
   1 2 3
  ------
a| O _ _ 
b| _ X _ 
c| _ _ _ 

(X): 
```

### Технические детали

#### Представление поля игры

Поле игры нужно представить в виде матрицы — массива массивов. Необходимо хранить 3 состояния каждой клетки: X, O и пустая. Можно закодировать их в int, но для этих целей в Java есть более безопасное и правильное решение — enum:

```java
public enum Cell {
    X, O, EMPTY
} 
```

Создайте новый Java-class, выберите тип enum и введите значения через запятую. После вы можете создать массив с этим типом:

```java
Cell[][] field = new Cell[3][3];
```

Вы уже изучали двумерные массивы в Python, в Java работа с ними обстоит следующим образом: 

```java
Cell centerCell = field[1][1]; // Получение клетки из массива
field[0][0] = Cell.X; // Установка значения в массив
```

Чтобы присвоить конкретное значение массиву, обращайтесь к значениям enum через `.`:

```java
field[0][0] = Cell.EMPTY;
field[1][0] = Cell.X;
field[1][2] = Cell.O;
```

#### initializeGame

Из метода необходимо вернуть матрицу `Cell[][]`, которая будет представлять игровое поле. Внутри метода создать её и заполнить значениями `Cell.EMPTyY`.

#### formatGame

Превратить матрицу `Cell[][]` в строку согласно спецификации. Вернуть отформатированную строку.

Для реализации удобно использовать `StringBuilder`. Строки в Java неизменяемы, поэтому каждое добавление к строке новых элементов создаёт новую строку, что может бить по производительности. Чтобы этого избежать, используют вспомогательный класс-билдер. Пример:

```java
public static String calc() {
	StringBuilder builder = new StringBuilder(); // Получаем объект-билдер
	builder.append("Hello ");
	for (int i = 0; i < 5; ++i) {
		builder.append(i); // Через append можно добавлять строки, символы, числа и т. д.
	}
	builder.append('\n'); // Добавление переноса строки
	builder.append("Haha");

	/*
	Hello 12345
	Haha
	*/
	return builder.toString();
}
```

```java
char ch = (char) ('a' + 2) // ch == 'c'
```

#### isMoveAvailable

Вернуть true, если есть пустые ячейки на поле, иначе false.

#### checkWin

Проверить 3 строки, 3 столбца и 3 диагонали поля. Вернуть `Cell`:

- `X` — победил «крестик»;
- `O` — победил «нолик»;
- `EMPTY` — победителя пока нет.

Хорошим решением будет разбить метод на подметоды (тесты при этом пишите только на `checkWin`).

#### move

Принимает поле, ход игрока (в виде строки) и текущего игрока (в виде `Cell`). Парсит строку с ходом игрока, валидирует ход, если он корректный, меняет соответствующую ходу клетку на поле на знак текущего игрока. В случае невалидного хода кидает `IllegalArgumentException` с описанием проблемы в message эксепшена.

**tip:**

```java
char ch = 'c'
int pos = ch - 'a'; // отнимет коды символов и вернёт 2, т. к. 'c' на 2 больше, чем 'a'
```

#### main

Метод «сшивает» всю логику игры.

- Вначале инициализирует игру (метод `initializeGame`).
- Содержит цикл-обработчик, который выполняется, пока не найден победитель и есть возможность хода (см. реализованные методы `isMoveAvailable` и `checkWin`).
- Перед считыванием хода пользователя выводит поле в виде строки в консоль (метод `formatGame`).
- Обрабатывает считываемый ход с помощью метода `move` и исключения неверного ввода. 
- В конце игры выводит информацию о победителе или объявляет о ничьей.


### Тесты

Тесты на методы должны покрывать при необходимости разные случаи (то есть на один метод должно быть несколько тест-кейсов). Пример:

- `initializeGame`:
  - один тест-кейс, проверить, что поле заполнено пустыми клетками.
- `formatGame`:
  - пустое поле;
  - заполненное частично поле;
  - заполненное полностью поле.
- ...

### Плей-тесты

Тесты, внутри которых происходит взаимодействие нескольких функций, для проверки всей логики игры.

Пример такого теста:

- инициализирует поле;
- делает несколько ходов «крестиками» и «ноликами»;
- проверяет между ходами, что победителя нет;
- когда сделан победный ход, проверяет, что победитель появился.
